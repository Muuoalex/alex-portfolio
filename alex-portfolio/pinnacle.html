WEB DEVELOPMENT PROJECT

Pinnacle Investors Self-Help Group Website

🌐 Website Development

A responsive website developed for Pinnacle Investors, a youth-driven Self-Help Group based in Murang'a, Kenya. The website provides members and visitors with information about the group's activities, services, leadership, events and membership registration.

💻 Project Overview

I developed a website for Pinnacle Investors Self-Help Group to establish an online presence and make important organizational information easily accessible to members and visitors.

The website organizes the group's information into dedicated pages covering its background, services, constitution, leadership, events, legal status and membership registration.

🛠️ Technologies Used

HTML

Used to structure the website and organize its content and pages.

CSS

Used to style the website, navigation, banners, layouts and responsive elements.

Git & GitHub

Used for version control, managing project files and maintaining the website's source code.

Cloudflare Pages

Used to deploy and host the website online.

✨ Website Features

🏠 Home Page

Introduces Pinnacle Investors Self-Help Group, its mission, vision and values.

💼 Services

Provides information about the group's savings, investment and member services.

👥 Leadership

Presents the group's leadership structure and its officials.

📅 Events

Displays announcements, upcoming events and previous activities.

📝 Registration

Provides information about membership registration requirements.

📜 Constitution

Provides access to the group's constitution and organizational guidelines.

👨‍💻 My Role

I was responsible for designing and developing the website, organizing the content, implementing the page structure and styling the user interface.

I also managed the website's deployment through GitHub and Cloudflare Pages and resolved technical issues involving files, images and website hosting.
