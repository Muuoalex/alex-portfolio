WEB DEVELOPMENT PROJECT

Pinnacle Investors SACCO Website

🌐 Website Development

A responsive website developed to provide members and visitors with information about Pinnacle Investors SACCO, its services, leadership, events and registration.

💻 Project Overview

I developed a website for Pinnacle Investors SACCO to establish an online presence and make important information easily accessible to members and visitors.

The website organizes the SACCO's information into dedicated pages covering its background, services, constitution, leadership, events, legal status and registration.

🛠️ Technologies Used

HTML

Used to structure the website and organize its content and pages.

CSS

Used to style the website, navigation, banners, layouts and responsive elements.

Git & GitHub

Used for version control, project management and publishing the website online.

✨ Website Features

🏠 Home Page

Introduces Pinnacle Investors SACCO, its mission, vision and values.

💼 Services

Provides information about the services offered to members.

👥 Leadership

Presents the organization's leadership structure.

📅 Events

Displays announcements, upcoming events and previous activities.

📝 Registration

Provides information about membership registration requirements.

📜 Constitution

Provides access to information concerning the SACCO constitution.

👨‍💻 My Role

I was responsible for designing and developing the website, organizing the content, implementing the page structure and styling the user interface.

I also worked on deploying the website using GitHub Pages and troubleshooting issues involving files, images and website deployment.
